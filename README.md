# Audiora

Audiora is a music streaming and discovery application scaffold.

## Status

Initial project architecture only. Music, authentication, recommendations, and player features are not implemented yet.

## Structure

- `backend/`: Node.js and Express API scaffold
- `frontend/`: React, JSX, React Router, and Tailwind scaffold
- `docs/`: Project setup and architecture notes

## Local setup

```sh
cd backend && npm install
cd ../frontend && npm install
```

Run the backend with `npm run dev` from `backend/` and the frontend with `npm run dev` from `frontend/`.
